# VizieR

Use the `vizier` preset to query the large collection of published catalogs
served by TAPVizieR. Catalog table names, column names, units, and conventions
vary substantially.

Search or inspect metadata for the intended catalog first. Do not transfer a
schema assumption from Gaia, SIMBAD, or another VizieR catalog. Select one
identified table, inspect its columns, and begin with a small bounded sample.
