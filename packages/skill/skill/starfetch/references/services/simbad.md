# SIMBAD

Use the `simbad` preset for named objects, identifiers, classifications, and
bibliographic object information. SIMBAD's relational schema differs from
catalog-style services; inspect tables and columns before constructing joins.

Object types and identifiers may require service-specific joins. Confirm key
columns and returned meanings from metadata rather than assuming familiar
names. Keep region searches small and report whether classifications are
primary types or joined auxiliary values.
